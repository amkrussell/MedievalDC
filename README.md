# MedievalDC
This repository contains large files from the Medieval DC project, a digital guide to places in the metro DC area to learn about the Middle Ages.

View the OSF project page: https://osf.io/x2s53/overview?view_only=2c59202fe3184cc9bd1f628cfc1caabe
This repository includes pdf files of static webpages, a WARC recording of the website, and the project's Archiving Dossier Narrative. 

View the website: https://sites.google.com/cua.edu/medievaldc/home
